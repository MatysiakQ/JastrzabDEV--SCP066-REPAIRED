## 🇵🇱 Polski

Wydanie 2.0.1 zawiera poprawki cyklu życia SCP-066, regeneracji Hume Shield, dźwięku i konfiguracji.

### Poprawki
- Wyłączenie i przeładowanie pluginu sprząta wyłącznie jego role, sesje, ustawienia SS2, callbacki i klipy audio.
- Konflikty ID roli i keybindów są wykrywane przed uruchomieniem. Stare wpisy menu są usuwane po wyłączeniu.
- Opóźnione spawny i teleporty sprawdzają rundę, instancję pluginu i konkretne nadanie roli.
- Przy braku lub usunięciu schematu pozostaje widoczny model zombie.
- HP jest ustawiane przy nadaniu roli, bez dodatkowego leczenia po 0,5 s.
- HS regeneruje się niezależnie od SCP-049: domyślnie **10 HS/s po 10 s bez otrzymanych obrażeń**, z uwzględnieniem blokerów tarczy.
- Głośność korzysta ze skali **0–1**. Stare `volume: 100` jest ograniczane do 1 z ostrzeżeniem.
- Uszkodzony OGG nie blokuje pozostałych klipów. Sprawdzane są kanały, częstotliwość, długość i rozmiar pliku.
- Klipy są ładowane raz na instancję i mają prywatne aliasy; sprzątanie nie usuwa cudzych danych.
- Beethoven zapętla się przez czas ataku i jest zatrzymywany po zakończeniu lub przerwaniu.
- Concussed wymaga zaakceptowanego trafienia i nadal żywej ofiary w tej samej roli.
- Błędna podkomenda RA niczego nie usuwa. `remove` jawnie przenosi SCP-066 do obserwatorów; `give` odrzuca gracza mającego już CustomRole.
- Zaktualizowano README PL/EN, walidację konfiguracji i checklistę testów serwerowych.

### Balans i konfiguracja
Zachowano **2000 HP, 500 HS, 7 obrażeń/tick, 22 s ataku, 15 m zasięgu, 35% szansy spawnu i 25 s cooldownu po ataku**. Atak nadal przenika ściany, a Bloodlust zombie pozostaje aktywny. Pełny atak to 154 bazowe obrażenia na cel; kolejna aktywacja jest możliwa po około 47 s od poprzedniej.

Nowe ustawienia: `hume_shield_regen_rate`, `hume_shield_regen_delay`, `role_id`, `beethoven_keybind_id`, `eric_keybind_id`, `music_keybind_id`. Istniejący YAML ma pierwszeństwo przed domyślnymi wartościami; zalecana głośność to 0.8–1.

### Instalacja i weryfikacja
1. Wgraj **Scp066.dll** do `EXILED/Plugins/`, usuwając starszą kopię.
2. Zachowaj model oraz nagrania. Dotychczasowe paczki: [Audio.zip](https://github.com/MatysiakQ/JastrzabDEV--SCP066-REPAIRED/releases/download/v2.0.0/Audio.zip) i [schematics.zip](https://github.com/MatysiakQ/JastrzabDEV--SCP066-REPAIRED/releases/download/v2.0.0/schematics.zip). Dopasuj `schematic_name` do faktycznej nazwy; domyślnie `scp066`.
3. Audio: OGG Vorbis, mono, 48 kHz; katalog `EXILED/Configs/Plugins/scp066/Audio/`.
4. Wymagane EXILED Events/CustomRoles/Permissions, ProjectMER i AudioPlayerApi z zależnościami. Cel kompilacji: net481, x64; referencje EXILED 9.13.2 i LabApi 1.1.6.

Kompilacja Release i **25 sprawdzeń regresji** przeszły. Testy sprawdzają produkcyjny kod konfiguracji oraz audio z rzeczywistymi AudioPlayerApi i NVorbis. **Testy serwera i klientów pozostają wymagane** — szczególnie HS, kamera, model, teleport, cykl rundy oraz zgodność z używanymi wersjami bibliotek. Checklistę zawiera `docs/TESTING.md`.

## 🇬🇧 English

Version 2.0.1 fixes SCP-066 lifecycle isolation, Hume Shield regeneration, audio handling and configuration.

### Fixes
- Unloading/reloading cleans only this plugin's roles, sessions, SS2 settings, delayed work and audio data.
- Role/keybind ID conflicts are detected before startup, and old menu entries are removed.
- Delayed spawn/teleport callbacks validate the round, plugin instance and exact role session.
- Missing or removed schematics retain the visible zombie model.
- HP is assigned on spawn without a delayed refill.
- HS regenerates independently of SCP-049: **10 HS/s after 10 s without received damage** by default, respecting shield blockers.
- Volume uses a **0–1 amplitude multiplier**. Legacy `volume: 100` is clamped to 1 with a warning.
- A malformed OGG no longer disables other clips; channel count, sample rate, duration and file size are validated.
- Audio is loaded once per plugin instance under private aliases; cleanup preserves foreign data.
- Beethoven loops for the attack duration and stops when the attack ends or is cancelled.
- Concussed requires an accepted hit against a living target still in the same native role.
- Invalid RA subcommands do nothing. `remove` explicitly moves SCP-066 to Spectator; `give` rejects players already holding a custom role.
- Updated PL/EN documentation, configuration validation and server test checklist.

### Balance and configuration
Retained: **2000 HP, 500 HS, 7 damage/tick, 22 s attack, 15 m radius, 35% spawn chance and 25 s cooldown after completion**. Wall penetration and native zombie Bloodlust remain enabled. A full attack deals 154 base damage per target, with about 47 s between activations.

New settings: `hume_shield_regen_rate`, `hume_shield_regen_delay`, `role_id`, `beethoven_keybind_id`, `eric_keybind_id`, `music_keybind_id`. Existing YAML overrides defaults; recommended volume is 0.8–1.

### Installation and verification
Install **Scp066.dll** into `EXILED/Plugins/` and remove older copies. Keep existing model/audio assets; the previous packages linked above remain available. Match `schematic_name` to the actual model name (default: `scp066`). Audio requires Vorbis mono 48 kHz under `EXILED/Configs/Plugins/scp066/Audio/`.

Requires EXILED Events/CustomRoles/Permissions, ProjectMER and AudioPlayerApi with their dependencies. Build target: net481, x64; included references: EXILED 9.13.2 and LabApi 1.1.6.

Release compilation and **25 regression assertions** passed against production configuration/audio code with real AudioPlayerApi and NVorbis. **Live server/client testing is still required**, especially HS, model/camera, teleportation, round transitions and compatibility with the target dependencies. See `docs/TESTING.md`.
